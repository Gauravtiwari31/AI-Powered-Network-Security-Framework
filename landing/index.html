The pipeline

Cheapest check first. Most expensive last.

Every packet walks the same ordered gauntlet. A blacklist hit costs a dictionary lookup; the ML layer only ever sees flows that survived everything before it — and only once a flow is old enough to describe.

00

Allowlist

Loopback, DHCP, link-local. Never dropped, so the engine can't lock you out.

01

Static rules

IP and port blacklists, shared by both platform front-ends.

02

Fragments

Tiny-first-fragment evasion and fragment floods, with bounded state.

03

Signature DPI

Regex over the reassembled stream — not one lonely packet at a time.

04

Entropy

Shannon bits/byte exposes DNS tunnels and packed payloads in cleartext.

05

Behaviour

Sliding windows catch port sweeps and SYN floods per source.

06

Flow ML

RF + LR consensus on real CICFlowMeter features. Monitor-only by default.

The ML layer ships disabled for blocking. It scores and logs, but never drops a packet until you flip ML_ENFORCE yourself — because a model validated on a 2018 dataset has not been validated on your network. Rules, DPI and heuristics do the enforcing until then.

Capabilities

What it actually catches

Every item below is pinned by a test in tests/test_detection.py.

Stream reassembly defeats split-payload evasion

Splitting UNION SEL / ECT across two TCP segments walked straight past the old per-packet matcher. Signatures now run against a rolling per-direction buffer, so the attack is caught on the segment that completes it.

Shannon entropy

Oversized high-entropy DNS payloads mean encoded data, not lookups. Ports that legitimately carry ciphertext are exempt — flagging :443 for looking encrypted is nonsense.

Scans & floods

Per-source sliding windows flag a sweep at 15 distinct ports in 10s and a flood at 100 SYNs in 5s — while the same ports touched slowly stay allowed.

JA3 that actually matches

Parsed from raw TLS bytes in wire order with GREASE stripped. Sorting the cipher list — as the old code did — produces hashes no public threat feed can ever match.

Signature set

SQLi (union, tautology, time-based, file-write), XSS, path traversal, SSRF to cloud metadata, command injection, Log4Shell and Shellshock — each carrying its own severity weight.

Threat scoring

Layers contribute weighted evidence and a packet drops at score ≥ 80. One weak signal can no longer veto your traffic on its own.

IPv6, finally

Parsing every packet as IPv4 gave IPv6 traffic an address of 0.0.0.0 and a free pass through every rule. Version is now read from the header nibble.

One engine, two platforms, bounded memory

Linux (NetfilterQueue) and Windows (WinDivert) are thin transport shims over a single detection_engine.py, so the two can never drift apart. Flow and per-source tables are capped and swept on a timer — a spoofed-source flood can't turn the firewall into the denial-of-service vector.

Quickstart

Watch it before you arm it

The demo sniffer classifies live traffic without dropping anything and needs no kernel driver. Start there, then move to active prevention.

passive — nothing is dropped
# 1. Install (platform packet driver resolves automatically)
pip install -r requirements.txt

# 2. Classify live traffic, block nothing
python demo_sniffer.py --quiet

# 3. Prove the layers work
python -m pytest tests/ -v
61 passed
windows — run as administrator
# WinDivert intercepts and drops in the network stack
python windows_active_firewall.py --monitor   # log only
python windows_active_firewall.py             # enforce

# Ctrl+C prints a session summary
linux — run as root
# Redirect traffic into userspace (v4 and v6)
sudo iptables  -I INPUT  -j NFQUEUE --queue-num 0
sudo ip6tables -I INPUT  -j NFQUEUE --queue-num 0

sudo python3 dpi_firewall.py --monitor        # log only
sudo python3 dpi_firewall.py                  # enforce

# Remove the rules when you are done
sudo iptables -D INPUT -j NFQUEUE --queue-num 0
